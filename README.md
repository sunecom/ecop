# AiToMoney · ECOP 计算平台技术验证

面向客户山东伊西欧普节能技术有限公司（ECOP）的 Web 计算验证项目。页面动态展示当前 DWSIM MCP 引擎的设备、物性、流程建模、求解和动态能力目录，并提供六个由真实引擎求解的纯水基础工作流。

当前可运行范围：目标汽化、按出口温度加热/冷却、泵升压；统一输出输入工况、主指标、出口状态、校核结果和 DWSIM 原始证据。浏览器支持本轮会话记录导出及同模块同指标比较，刷新后清空会话列表。组分搜索与物性包名称来自真实目录，但在线计算仍只开放 Water + Steam Tables。目录中的“引擎可用”模块不代表网页已实现对应工程流程；板式蒸发器选型、盐溶液浓缩、多效蒸发及 MVR 系统设计尚未实现。

- `本地演示/`：页面、计算适配器与 Windows 本地启动说明。
- `deploy/`：Linux 容器、配置模板及部署/回退说明，详见 [部署说明](deploy/README.md)。
- 在线地址：`https://ecop.aitomoney.online`（Basic Auth 受控访问）。

本仓库只包含项目应用与部署文件，不包含本地 SDK、上游完整源码、凭据、客户计算记录或研究报告。DWSIM 采用官方单独容器，通过内网 MCP 连接，遵循上游许可证和原作者版权。
