# AiToMoney · ECOP 计算平台技术验证

面向客户山东伊西欧普节能技术有限公司（ECOP）的 Web 计算验证项目。浏览器输入工况，由真实 DWSIM MCP 引擎计算纯水加热汽化结果。

当前范围：纯水流量、入口温度、绝对压力与汽化比例；输出热负荷、出口温度、汽化量及原始计算证据。板式蒸发器选型、盐溶液浓缩、多效蒸发及 MVR 系统设计尚未实现。

- `本地演示/`：页面、计算适配器与 Windows 本地启动说明。
- `deploy/`：Linux 容器、配置模板及部署/回退说明，详见 [部署说明](deploy/README.md)。
- 规划域名：`ecop.aitomoney.online`，仅在 DNS、HTTPS 和算例验收后确认上线。

本仓库只包含项目应用与部署文件，不包含本地 SDK、上游完整源码、凭据、客户计算记录或研究报告。DWSIM 采用官方单独容器，通过内网 MCP 连接，遵循上游许可证和原作者版权。
