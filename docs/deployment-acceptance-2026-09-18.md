## 上线功能

1. 能力总览实时返回 48 个云端 MCP 工具、44 种单元操作、28 个物性包和 1611 条组分记录。
2. 设备库区分“已接入可运行”“引擎可用、网页待接入”“桌面或扩展能力”；只有完成专用参数和验收流程的 `Heater`、`Cooler`、`Pump` 标记为可运行。
3. `/api/compounds?q=` 在真实引擎目录缓存中搜索并只返回前 20 项；网页的物性包筛选使用引擎返回的准确名称。
4. 在线工作台提供目标汽化、按出口温度加热/冷却、泵升压三类实际 DWSIM 求解。
5. 每次求解都使用独立 flowsheet，并在 `finally` 中关闭；单引擎锁保持串行。只有目标值、相态和物料衡算通过后才返回成功。
6. 浏览器本轮会话记录支持逐条与整轮 JSON 导出，只允许比较同模块、同指标、同单位的两个工况；刷新页面即清空浏览器会话列表。

## 边界

在线计算仅验证纯水与页面给出的温压范围，统一采用 Steam Tables (IAPWS-IF97)。1611 条组分可搜索不代表全部组分都已开放计算。板式蒸发器选型、盐溶液浓缩、多效蒸发、MVR、机械设计、材料选择与安全审查仍不在本版本范围内。

结果记录中的 `commit` 字段标识固定 DWSIM 镜像摘要，不将其与本机源码 pin 或应用 Git 提交混淆。
