# P2 组分与物性包受控工作流设计

## 范围

- 纯物质：Water、Ethanol、Acetone。
- 非电解质二元混合物：Water–Ethanol，用户输入乙醇质量百分数。
- 物性包：Water 仅允许 `Steam Tables (IAPWS-IF97)`；Ethanol、Acetone、Water–Ethanol 允许 `NRTL` 与 `Raoult's Law`。
- 计算：进料组成采用质量分数，Heater `OutletVaporFraction` 明确采用 DWSIM 摩尔相率规格；质量组成基准与汽相摩尔率不得混用。
- 明确排除：任意 1611 组分开放、盐/电解质、工业废水、结垢、反应与工程选型。

## 强制契约

- 组成输入基准固定为质量分数；总和必须归一为 1，二元乙醇质量百分数限定 5–95%。
- 设置组成后必须重新设置总质量流量，随后回读组分名、质量分数、质量分数总和和总流量。
- 物性包必须由白名单映射到引擎全名；`dwsim_thermo_set_property_package` 返回值必须与请求完全一致。
- 求解后回读整体组成、汽液相质量/摩尔组成、总质量/摩尔流量、压力和汽相摩尔率；由总摩尔流量、摩尔相率及相摩尔组成重建汽液相流量，并校核 `m_feed*z_i = m_vapor*y_i + m_liquid*x_i` 的分组分质量闭合及对应摩尔闭合。
- 非有限数、压力目标未达到、汽相目标未达到、物性包/组分/组成/流量回读不一致均不得生成成功记录；沿用服务器 `finally` 清理流程图。

## 对照与解释边界

- Water、Ethanol、Acetone 在 101.325 kPa 的两相闪蒸温度与 NIST Chemistry WebBook 常压沸点作量级筛查；不设置没有文献依据的硬偏差容差。
- Water–Ethanol 分别使用 NRTL 和 Raoult 求解并比较结果差异，仅用于证明物性包选择真实作用于模型。Raoult 明确为理想溶液对照，不标为工程推荐。
- 当前 MCP 未暴露 NRTL 二元交互参数的具体来源与有效温区，因此记录为未知项；收敛不代表参数适用。
- 守恒、一致性和参考点接近只证明实现与所选模型一致，不证明该物性包对任意工况具有工程准确性。
