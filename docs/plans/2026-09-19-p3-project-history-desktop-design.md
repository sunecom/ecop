# P3 项目保存、历史复用与桌面互通设计

## 目标与边界

P3 在不改变现有十个受控计算工作流数值边界的前提下，增加认证用户隔离的项目、工况版本、不可变计算记录和 DWSIM 流程文件导出。项目数据写入独立持久化卷；原 `/data/runs/*.json` 作为旧记录来源，只做幂等迁移，不删除、不覆盖。浏览器只能提交服务生成的稳定 ID，不能提交或拼接服务器文件路径，也不增加任意文件上传或执行能力。

## 方案比较

1. **SQLite 元数据 + 共享导出目录（采用）**：Web 将项目、版本、记录和导出映射写入 SQLite；Web 与固定 DWSIM 容器以相同 UID 共享独立项目卷，DWSIM 只接收服务端生成的导出路径。事务、唯一约束和外键可直接保证不可变关系，备份恢复也只需一致复制一个卷。
2. **继续使用 JSON 目录**：改动小，但并发、去重、版本号分配、跨记录查询和恢复一致性较弱，不适合项目/版本关系。
3. **引入外部数据库与对象存储**：扩展性强，但 P3 单用户受控候选不需要新增服务、凭据和运维面，超出当前范围。

## 数据契约

- `projects`：稳定 `prj_` ID、认证主体 ID、名称、创建/更新时间。
- `cases`：稳定 `case_` ID、所属项目、名称、创建时间；逻辑工况本身不承载可变输入。
- `case_versions`：稳定 `cv_` ID、工况内单调版本号、父版本、严格校验后的输入 JSON、创建时间。创建后禁止更新。
- `calculation_records`：沿用计算 `run_id`，关联精确工况版本，保存完整结果 JSON、引擎版本、引擎构建引用、创建时间。创建后禁止更新。
- `exports`：稳定 `exp_` ID、关联计算记录、服务端相对路径、SHA-256、字节数、创建时间。API 永不返回绝对路径。
- 认证主体 ID 由服务端根据认证方式和用户名生成固定 SHA-256 映射；数据库不依赖浏览器传入用户 ID。

所有写操作启用外键和事务。SQLite 使用 WAL、`busy_timeout` 和独立连接；数据库文件、导出文件都位于 `/projects` 独立卷。项目详情按项目→工况→版本→记录层级返回，输入与结果均从不可变快照读取。

## 计算与导出流程

1. 浏览器创建项目和工况版本，只提交名称、受控工作流输入及稳定父 ID。
2. 服务端读取版本输入并再次调用现有 `validate`，生成 `exp_` ID 和位于共享卷内的固定 `.dwxml` 路径。
3. `calculate` 使用现有单引擎锁求解；结果、目标值和守恒全部通过后，在 `finally` 关闭 flowsheet 之前调用 `dwsim_flowsheet_save`。
4. Web 侧确认导出文件存在、为普通文件、后缀正确且解析后的路径仍位于导出根目录，然后计算 SHA-256。
5. 单个事务写入计算记录与导出映射。若求解、保存、哈希或数据库写入失败，不登记成功记录，并清理未登记的临时导出。
6. 下载 API 只接受 `exp_` ID，经认证主体和数据库映射取回文件；拒绝 `..`、斜杠、绝对路径、其他主体 ID 和不存在 ID。

普通 `/api/calculate` 仍保留无项目的即时计算及原 JSON 记录行为。项目版本计算才生成可被桌面打开的 DWSIM 文件，JSON 下载不再被描述为流程导出。

## 历史、比较与恢复

- 首次初始化为当前认证主体创建“历史记录迁移”项目，并按 `run_id` 幂等导入合法旧 JSON；损坏、非对象、缺少稳定字段的文件记录为迁移统计，不中断服务。
- 比较要求模块 ID、设备类型、主指标、单位、物性包、物料系统与组成基准一致；否则返回不可比原因。
- Web 重建后从 SQLite 恢复项目和记录。备份采用 SQLite 在线备份 API，恢复测试在新目录打开副本并核对项目、版本、记录、导出哈希。
- DWSIM 桌面对照使用候选导出的 `.dwxml`，执行打开→重新求解→另存，比较温度、压力、相率及功率/热负荷等关键结果；只声明同模型一致性。

## 页面与错误处理

新增“项目与历史”面板：创建/选择项目、从当前表单保存工况、打开版本、复制版本、改参生成新版本并重算、查看不可变记录、比较兼容记录、下载 DWSIM 文件。所有写请求沿用 Origin + nonce；认证由 Basic Auth 服务端主体映射完成。页面刷新后重新加载服务端项目，390 px 下表格可横向滚动且不截断操作按钮。

错误响应不泄露数据库路径、导出路径、MCP 错误或凭据。并发计算仍由单进程 `LOCK` 串行；SQLite 锁冲突返回受控错误。P3 不修改生产，只构建独立候选，生产部署继续等待总控复核。

## 验收

- 单元：稳定 ID、不可变版本、跨用户隔离、非法 ID/路径拒绝、比较规则、旧记录幂等迁移、重启持久化、备份恢复。
- 集成：真实 DWSIM 基准与扰动项目版本计算、每次生成独立流程文件、旧记录不变、Web 重建后恢复。
- 桌面：DWSIM 10.2.8 打开候选导出并重新求解，关键结果在预先声明容差内一致。
- 浏览器：真实 Chrome 完成创建项目→保存工况→重算→刷新恢复→比较→下载；1440/390 无关键截断，console/page error 为 0。
