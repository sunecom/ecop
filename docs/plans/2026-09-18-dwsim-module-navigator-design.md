# DWSIM 模块总览与导航设计

## 目标与边界

在保留现有纯水加热汽化真实算例的前提下，让 ECOP 用户看见当前 DWSIM 引擎的能力结构。页面必须区分“网页已接入可运行”“引擎已有但网页待接入”“仅桌面或需要扩展组件”，不能把 MCP 工具数量等同于 DWSIM 模块数量，也不声称复刻桌面版。

## 信息架构

1. 能力总览：分别展示 MCP 工具、单元操作类型、物性包和组分记录四种统计口径。
2. 设备模块库：将实时枚举的 44 种单元操作分为传热与储运、分离与塔器、反应与生化、清洁能源、流程逻辑五组；支持搜索、分类和状态筛选。
3. 物性与组分：展示组分计数、当前算例选择和 28 个物性包的准确名称。
4. 建模与求解：按流程生命周期、热力学、物流、设备、求解、图形、动态七组展示 48 个 MCP 工具及说明。
5. 动态与扩展：说明 17 个动态工具的工作链，并把桌面优化、数据回归、反应管理和 CAPE-OPEN 等能力单独标记。
6. 在线工作台：接入目标汽化、按出口温度加热/冷却、泵升压三类纯水流程，统一展示结果、校核与原始证据。
7. 会话记录：浏览器内存保存本轮结果，支持逐条/整轮 JSON 导出，并只允许比较同模块、同指标、同单位的两次工况；刷新页面即清空。

## 数据与安全

后端提供经过 Basic Auth 保护的只读 `/api/catalog`。它只调用固定白名单：`tools/list`、`dwsim_unitop_list_types`、`dwsim_thermo_list_property_packages` 和 `dwsim_thermo_list_compounds`，随后关闭临时流程并缓存结果。接口不接受工具名、参数或文件路径，不提供通用 MCP 代理，也不返回 token 或完整组分列表。首次采集与真实计算共用进程锁，避免并发操作单一引擎。

中文名称、分类、输入输出和适用场景属于页面策展元数据；设备存在性、物性包、组分计数和工具列表来自实际引擎。`Heater`、`Cooler` 和 `Pump` 对应的三类受控流程标记为可运行。组分搜索只在服务端缓存的真实目录中匹配并返回前 20 项，不代表全部组分都能由在线工作台计算。

## 可执行流程

1. 目标汽化：`Heater / OutletVaporFraction`，输入纯水流量、入口温度、绝对压力和目标汽化比例；校核目标汽相分数和物料衡算。
2. 出口温度：依据目标温度自动选择 `Heater` 或 `Cooler`，输入纯水流量、入口温度、绝对压力和出口温度；校核目标温度、单液相和物料衡算。
3. 泵升压：`Pump / OutletPressure`，输入纯水流量、入口温压、出口压力和效率；输出轴功率、水力功率与出口状态，并校核目标压力和单液相。

## 交互与视觉

视觉采用工业制图台风格：深海军蓝主场、蓝色接口状态、绿色可运行状态、琥珀色边界提示，配合网格纸背景和等宽数据字体。设备卡点击打开详情对话框；未接入模块只展示状态说明，不提供假运行按钮。页面在桌面端提供四列设备网格，在移动端降为单列并保留搜索、筛选和计算操作。

## 验证

- 单元测试覆盖目录认证、只读返回、错误隐藏和既有计算适配器。
- 冒烟测试断言 48 个工具、44 种设备、28 个物性包、至少 1500 条组分记录及三个已接入设备类型。
- Linux 冒烟对三类工作流各执行基准与扰动工况，共六次真实求解，并验证趋势、目标值和物料衡算。
- 浏览器检查桌面与移动布局、搜索/筛选、组分与物性查询、三个表单、记录导出及同指标比较保护。
- 部署后分别通过回环和公网 HTTPS 运行完整冒烟，并复核 DWSIM 无宿主端口、旧算例数值不变。
