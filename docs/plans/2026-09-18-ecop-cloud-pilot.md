# ECOP 云端受控演示部署计划 V0.1

用户授权：由程序设计分控在本机开发后上传到小龙女服务器，使用 ecop.aitomoney.online，GitHub sunecom/ecop。总控负责 SSH 凭据、GitHub key、DNS及公网反向代理，分控负责独立应用部署与真实计算验证。

采用独立 Docker Compose（Web WSGI + 官方固定摘要 DWSIM MCP），保留本机演示入口。相比直接公开 Python demo，可增加认证、进程服务管理、内网隔离与资源限制；相比立即建立完整微服务队列平台，适合当前单用户技术验证阶段。

执行：核验上游镜像与启动参数 → 实现环境配置和认证适配 → 本地验证 → 只读盘点目标服务器 → 上传精选源码到 /opt/ecop → 构建独立容器 → Linux真实算例验证 → 总控接入域名及 HTTPS。

接受标准：未登录业务路由401；跨站计算403；合法工况调用真实引擎；基准值与Windows结果一致；不存在MCP公网端口；无其他服务修改；所有密钥、SDK、运行记录、研究源文件排除Git。不能将仅编译/模拟测试称为Linux运行成功。
